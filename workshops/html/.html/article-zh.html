文档清洗入门指南

本页是 HTML workshop 的中文样例，涵盖标题、段落、列表、表格等常见结构。清洗目标是去掉噪声、保留阅读顺序，并输出适合 RAG 分块的文本。

一、为什么要清洗

原始 HTML 常含导航栏、侧边栏、广告、脚本和页脚链接。如果直接入库，检索结果会被无关内容污染。清洗阶段应识别正文区域，丢弃模板重复块，并合并多余空白。

对于中文页面，编码通常为 UTF-8，但仍需确认 meta 标签与文件实际编码一致。混合中英文段落时，不要在中英文之间插入多余空格，除非原文如此。

  • 去掉页眉、页脚、面包屑导航
  • 提取标题与正文段落
  • 保留表格行列关系
  • 列表项按 DOM 顺序输出
    • 嵌套列表应保留层级
    • 有序与无序列表不要混淆
  • 记录 parse_warnings 便于人工复核

二、常见 HTML 元素

下表说明各类标签在解析结果中的建议映射方式。

元素 块类型 说明
标题 h1-h6 title 用标签级别或字号推断章节层级
段落 p paragraph 合并连字符断行，压缩连续空白
表格 table table 按行从左到右、从上到下展开
列表 ul / ol list 保留项目符号或序号
链接 a link 优先保留锚文本，必要时附带 URL
表单 form metadata 默认不当作正文，除非业务需要

三、分块建议

  1. 优先按标题边界切分 chunk
  2. 表格在 token 允许时保持完整
  3. 章节标题写入 metadata，避免每个 chunk 重复粘贴
  4. OCR 或解析置信度低的内容单独标记

四、中文测试段落

人工智能是计算机科学的一个分支，研究如何让机器表现出类似人类的智能行为。典型应用包括自然语言处理、计算机视觉、推荐系统和知识问答。

在 RAG 系统中，文档解析质量直接影响召回与回答准确性。建议为每种文件类型准备代表性样本：基础页、表格页、中文页，以及像 SEC 10-K 这样的复杂脏 HTML。

测试词组：机器学习、深度学习、向量检索、语义分块、边界测试、解析警告。
